# Buykori Admin Portal

Vercel-ready static frontend for `admin.buykori.app`.

Set the Vercel project root to `admin-portal`.

Runtime API target:

```txt
https://api.buykori.app
```

The first version uses `X-Admin-API-Key` and the split-admin JSON endpoints under `/api/v1/admin/api`.

## Development

There is no build step. The deployed artifact is exactly what is in this
repository — `index.html` loads `app.js` directly via a classic `<script>` tag.
The tooling below only _checks_ the code; it never transforms it.

```bash
npm ci

npm run dev           # static server on http://localhost:5050
npm run lint          # ESLint 9; fails if the 94-warning baseline increases
npm run typecheck     # tsc --noEmit (allowJs, checkJs off)
npm run format:check  # Prettier, excluding the three large legacy files
```

### Two things not to break

1. **`app.js` is a classic script, not a module.** Inline `onclick=` handlers
   throughout `index.html` and inside HTML generated by `app.js` depend on its
   top-level functions being globals. Do not add `type="module"` and do not
   introduce a bundler until those handlers are gone.
2. **All user-supplied text must go through `esc()`** before entering an
   `innerHTML` sink. `eslint-plugin-no-unsanitized` now flags misses
   automatically; treat every one of its warnings as a real finding.

See [MIGRATION.md](./MIGRATION.md) for the staged plan to add type safety
without a rewrite.
